## 각 pane 응답 요약

### pane-2 (Codex gpt-5.5 · 데이터 소스)
- 전제: 한국 "오늘/6시간" 기준 현재 예보
- **무료 + 빠른 확인**: 기상청 초단기실황/예보 API + 레이더 (apihub.kma.go.kr) 1순위
- **정확도 최우선**: KMA 기준값 + Weather.com/AccuWeather 교차검증
- 앱별 내부 소스: 네이버=KMA+Weather Channel·AccuWeather, 삼성=Weather.com, Apple=Apple Weather

### pane-3 (Gemini 2.5 Pro · UX 대안)
1. **일반 사용자 (편의성)**: iOS 날씨 / Samsung Weather — 위젯·잠금화면·워치 연동
2. **빠른 확인**: Siri/Bixby 음성 — "오늘 날씨 어때?"
3. **전문 활동**: Windy / Weather Underground — 바람·파고 등 전문 정보
4. **가장 단순**: 웹 검색 "서울 날씨" — 설정 불필요

### pane-4 (Claude Sonnet · 일상 루틴)
- **1단계(5초)**: 알람 끄며 잠금화면 위젯 — 기온·강수확률·미세먼지
- **2단계(0 노력)**: 씻으면서 AI 스피커 ("헤이 클로바, 오늘 날씨") 또는 7~8시 라디오 교통정보
- **3단계**: 현관 전 창밖 3초 — 실제 바람/습도로 겉옷·우산 결정
- 핵심: **시각(위젯) + 청각(스피커) + 체감(창밖)** 3채널 루틴화

### pane-5 (Gemini 2.5 Flash · 속도 비교)
| 방법 | 속도 | 정확도 | 정보량 | 편의성 |
|---|---|---|---|---|
| 모바일 앱 | 빠름 | 높음 | 많음 | 매우 좋음 |
| 음성 비서 | 즉시 | 보통 | 간단 | 매우 좋음 |
| 웹 검색 | 보통 | 높음 | 많음 | 보통 |
| 기상청 사이트 | 느림 | **최상** | 매우 많음 | 낮음 |
| 스마트워치 | 매우 빠름 | 좋음 | 적음 | 매우 좋음 |
- 종합: 빠른 확인엔 모바일 앱/음성, 상세 정보엔 기상청
